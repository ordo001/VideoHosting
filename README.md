# Video Hosting

![Video Hosting](https://img.shields.io/badge/Status-Development-yellow)

## Описание проекта

Проект представляет собой **видеохостинг** на базе **ASP.NET Core**, с модульной архитектурой.  

Он включает:

- **API** для загрузки видео, управления пользователями и видео  
- **Worker Service** для фоновой обработки видео с использованием **FFmpeg**  
- **MinIO / S3** для хранения видеофайлов  
- **RabbitMQ** для очередей задач обработки видео  
- **PostgreSQL** для хранения метаданных видео и пользователей  

**Основные возможности:**

- Загрузка видео с presigned URL  
- Обработка видео и генерация HLS потоков (3 качества + master.m3u8)  
- Генерирует превью видео  
- Фоновая обработка через Worker Service

# Структура базы данных

### База данных `AuthDb` - хранит информацию о пользователях
Таблица `Users`

| Поле          | Тип        | Описание                     |
|---------------|-----------|-----------------------------------------------|
| Id            | UUID      | Уникальный идентификатор                  |
| Login         | string    | Логин для авторизации пользователя                            |
| Name          | string    | Имя пользователя                           |
| PasswordHash  | string    | Хэш пароля         |
| RoleId     | UUID  | Уникальный идентификатор роли          |

Таблица `Roles`

| Поле          | Тип        | Описание                     |
|---------------|-----------|-----------------------------------------------|
| Id            | UUID      | Уникальный идентификатор                   |
| Name         | string    | Название роли                           |

### База данных `FileDb` - хранит метаданные видео
Таблица `Video`

| Поле          | Тип        | Описание                     |
|---------------|-----------|-----------------------------------------------|
| Id            | UUID      | Уникальный идентификатор                  |
| Title         | string    | Заголовок видео                            |
| Description   | string    | Описание видео                         |
| Status        | int    | Статус видео в системе (не загружен, загружено, в обработке, готово, ошибка обработки)        |
| Duration     | int  | Длительность видео         |
| isPublic     | bool  | Публичное ли видео       |
| PreviewUrl     | string  | Url обложки видео         |
| MasterUrl     | string  | Url мастер видео         |
| CreatedAt     | DateTime  | Дата добавления видео         |
